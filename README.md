# Rusiri Ranmini — Portfolio Starter

A responsive, monochrome manga-inspired personal portfolio built with plain HTML, CSS, and JavaScript. Designed to publish using GitHub Pages.

## Included
- Responsive dark portfolio layout
- Featured projects: SmartCare-AI, SMS Spam Detection, MindMate AI, WISEC
- About, skills, experience, contact sections
- Media Unit archive with filters for events, leadership, and initiatives
- Mobile navigation and active section highlighting

## Open in VS Code
1. Extract the ZIP file.
2. In VS Code, choose **File → Open Folder** and select `tessa-portfolio-starter`.
3. Open `index.html`.
4. For a live preview, install the **Live Server** extension, right-click `index.html`, and choose **Open with Live Server**.

## Important edits before publishing
1. Replace `your-email@example.com` with your professional email.
2. Replace the LinkedIn `href="#"` with your profile URL.
3. Replace the GitHub profile links on each project card with the exact repository URL.
4. Add the illustration you want to use as `assets/portfolio-illustration.png`. The page shows a placeholder if it is missing.
5. Verify role titles, dates, and responsibilities before publishing.
6. Add real screenshots, certificates, event photos, and public evidence only where you have permission to share them.
7. Remove any skills or technologies you cannot confidently discuss.

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `tessa30s.github.io` (if available).
2. Upload the contents of this folder to the repository root, so `index.html` is at the top level.
3. In the repository, open **Settings → Pages**.
4. Select deployment from the `main` branch and `/ (root)`, then save.
5. Wait for the GitHub Pages deployment to finish and open the URL shown there.

## Notes
This is a starter, not a claim that every listed role or contribution has been verified. Archive cards intentionally identify details that still need confirmation. Update them with accurate personal contributions before making the site public.
